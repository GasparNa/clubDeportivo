# Colores de estado del sistema

Estos son los únicos colores funcionales documentados aquí. Los colores de marca y de superficie pertenecen a la skill `club-deportivo-visual-design` y a los tokens globales del frontend.

- Disponible / éxito: `#4ADE80`
- Advertencia / quedan pocos turnos: `#FBBF24`
- Error / acción destructiva: `#F87171`
- Información / referencia: `#60A5FA`
- Inactivo / deshabilitado: `#64748B`

Los estados deben acompañarse con texto, icono o una etiqueta accesible; el color no debe ser el único medio para comunicar el significado.
