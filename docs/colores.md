# Colores de la aplicación

## Modo Claro — "Cancha de Día"
Inspiración: césped, cielo, limpieza. Ideal para usar de día y para que la disponibilidad se lea al instante.

Primary #0E9F6E: Botón principal, estado Disponible, tabs activos
Primary Hover #0B7A55: Hover y pressed
Secondary #0F172A: Headers, navegación, texto de precio
Accent #F59E0B: CTA secundario, "Quedan pocos turnos", badges de promo
Background #F8FAFC / Surface #FFFFFF / Surface 2 #F1F5F9: Fondo, cards y lista de horarios
Text Primary #0F172A / Secondary #64748B: Títulos y descripciones
Border #E2E8F0: Separadores
Success #16A34A / Warning #F59E0B / Error #EF4444: Estados de turno

## Modo Oscuro — "Cancha de Noche"
Inspiración: partido nocturno con reflectores. El verde se vuelve neón para que resalte sobre fondo profundo.

Primary #22C55E: Botón principal y focos de disponibilidad. Brilla sin quemar la vista
Primary Hover #4ADE80: Para efectos de hover
Secondary #60A5FA: Links, filtros, icono de ubicación
Accent #FBBF24: Reservar, favorito, iluminación
Background #070F1E / Surface #111F35 / Surface 2 #1A2E4D: Fondo profundo y cards elevadas
Text Primary #F1F5F9 / Secondary #94A3B8: Contraste AA+ garantizado
Border #1E3A5F: Bordes sutiles
Success #4ADE80 / Warning #FBBF24 / Error #F87171: Versiones luminosas para dark
